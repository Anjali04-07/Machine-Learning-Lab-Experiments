## Aim

## Objectives

- To identify missing values and duplicate records.
- To calculate basic statistical measures.
- To visualize data using different charts and graphs.
- To identify patterns, trends, and relationships between variables.

## Theory

Exploratory Data Analysis (EDA) is the process of examining and understanding data before applying Machine Learning algorithms. It helps identify data quality issues, distributions, unusual values, and relationships between features.

Data visualization represents information graphically, making it easier to understand patterns and trends.

### 1. Data Inspection

Data inspection involves checking the number of rows and columns, data types, column names, and sample records.

### 2. Descriptive Statistics

Descriptive statistics summarize numerical data using measures such as:

- Mean
- Median
- Standard deviation
- Minimum and maximum values
- Quartiles

### 3. Data Visualization

Different visualization techniques help understand different aspects of data:

- **Histogram:** Shows the distribution of a numerical feature.
- **Bar Chart:** Compares values across categories.
- **Box Plot:** Displays the spread of data and potential outliers.
- **Scatter Plot:** Shows the relationship between two numerical variables.
- **Heatmap:** Displays correlations between numerical features.
